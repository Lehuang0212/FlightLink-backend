# 通道恢复与升级（SQLite schema 5）

升级前用 SQLite backup 备份数据库，保存部署版本与配置。旧版本不能打开 v5；需要回退时应恢复匹配版本的备份，并核对升级后发生的云规则变更。

- `enabled` 只表示用户配置。只有启用且 `runtime_intent=applied` 才允许在启动恢复或手动重启时运行 Router。迁移将原 `synced`/`disabled` 记录标为 applied；其余旧记录无法可靠区分失败创建、更新和删除，保守阻止运行。请在维护窗口升级，逐组确认后重新保存配置或继续删除。
- 删除意图在停止服务之前写入；失败后只允许重试删除，API 重启不会恢复这些通道。启动不访问阿里云。`disabled` 安全组状态指未托管，不代表无需防火墙规则。
- 抓包为诊断功能：启用通道时抓包失败不回退已应用的 Router 配置；停用和删除仍要求停止抓包。创建和更新响应含 `operation_result`，GET 只读状态，不负责恢复监听器。
- `/messages`、`/packets` 支持可选 `after` 游标；响应 `reset=true` 时替换窗口（新会话、窗口溢出或游标过期），否则追加。日志保留完整统计区块，窗口未变化返回空增量，变化时替换。它们均不是连续审计记录。
