# FlightLink-Console 后端 / Backend

管理飞控、4G DTU、ECS 与 QGC 之间的 MAVLink 通信通道，提供服务控制、遥测、日志、抓包和阿里云安全组同步。

Manages MAVLink channels between flight controllers, 4G DTUs, ECS, and QGC, with service control, telemetry, logs, captures, and cloud security-group synchronization.
